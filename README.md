# cen4802 Color Quiz
Version control workflow foundations repository

**Author:** Christina Gadson

## Description

Color Quiz is a small Java web application created for CEN4802 Software Integration, Configuration, and Testing. This web application presents users with five multiple-choice questions about basic colors and color mixing. After the user submits the quiz, a Java servlet evaluates the answers, calculates the score, and displays the final result in the web browser.

## Technologies

- Java 21
- Jakarta Servlets
- JSP
- Apache Tomcat 10.1
- HTML/CSS
- Git
- GitHub

## Running the Application

The application runs locally using Apache Tomcat and can be accessed through a web browser at:

`http://localhost:8080/cen4802/`

## Purpose

This application will serve as the foundation for later CEN4802 assignments involving version control, testing, integration, configuration, building, deployment, and other DevOps practices.
